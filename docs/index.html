ミニシティ

ドット絵で育てる箱庭の街づくり。サポートページです。

はじめかた

  1. 発電所を1つ置く
  2. 道路を引き、その脇に住宅区と工業区を並べる
  3. 送電線で発電所と区画をつなぐ（区画どうしは電気を通すので、線を引くのは最初の一本だけで足ります）
  4. 時間を進める。人が入れば商業の需要が立ち上がります

操作

  • 移動：この道具を選ぶと、1本指のドラッグで地図が動きます
  • 拡大縮小：右下のつまみを上下になぞる。⊕ ⊖ を押せば1段ずつ動きます
  • 調べる：軽く叩くと、そのマスの土地価値や公害を読めます
  • 建設：1本指でマスを塗ります。道路と送電線はなぞって引けます
  • 2本指：どの道具でも地図を動かせます。つまめば拡大縮小

よくある質問

区画に稲妻やバツの印が出ます

稲妻は電気が届いていない印、バツは道路に面していない印です。 送電線をつなぐか、区画の外周のどこかが道路に接するように敷き直してください。 発電所1つでまかなえる区画の数には上限があるので、街が広がったら発電所を足す必要があります。

人口が増えなくなりました

需要は職と住のつり合いから決まるので、街が育つと自然に釣り合って止まります。 そこから先へ伸ばすには、土地の値打ちを上げることになります。 公園を敷いて公害を吸わせる、警察署で犯罪を抑える、工業区を住宅から離す、といった手が効きます。

住宅がいつまでも小さいままです

工場や発電所の煙が近いと、土地の値打ちが下がって住宅が育ちません。 公害は「公害」の表示に切り替えると色の濃淡で見えます。 煙の出どころを離すか、あいだに公園を挟んでください。

最初からやり直したい

画面上部の資金額を押すと予算画面が開きます。一番下の「新しい都市をはじめる」から、 地形ごと作り直せます。元には戻せないので確認をはさみます。

データは保存されますか

自動保存されます。アプリを閉じても続きから再開できます。 保存先は端末内だけで、外部に送信されることはありません。
